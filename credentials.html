How Decentralized Credential Verification Works

Understanding the difference between cryptographic proofs, institutional trust, and on-chain immutability.

1. Hashes vs. Full Documents

Full student transcripts contain sensitive personal details. We generate a one-way cryptographic SHA-256 hash. If even a single grade or letter is modified, the hash changes completely.

2. The Role of Authorized Issuers

A hash alone does not prove a degree is real unless the issuer's public key belongs to an accredited university or authority. In a complete production architecture, institutions sign hashes using their registered authority keypairs.

3. Zero Sensitive Key Storage

EduChain never requests or stores private keys, recovery phrases, or private documents. Wallet interactions are non-custodial and run strictly in the user's browser environment.
